# Documentation audit

> [!NOTE]
> The latest main/profile/conduct reconciliation is recorded in
> [the November 13 supplement](RECONCILIATION-20261113.md). Earlier evidence below remains tied
> to its original revision; it is not a test receipt for the new head.

All original and proposed public Markdown documents, including hidden GitHub templates, are reviewed
in the [file-by-file inventory](documentation-audit.json). Each record identifies purpose, issue
classification, treatment, source authority, acceptance criteria, and final disposition. No document
is classified from age alone.

## Current-state findings

The original main branch genuinely lacked a root README. The new root guide explains the repository;
`profile/README.md` remains the separate organization introduction. No placeholder `PROFILE.md`,
`AGENTS.md`, or `GOVERNANCE.md` is added simply to match a checklist.

The published policies, exact source, current canonical architecture and engineering governance, and
current owner direction were compared. The local Kernel copy differed from the authenticated current
source and was not treated as current authority. Detailed source identities and private policy
differences remain outside the public change set. Repository-specific disclosure rules are not
silently replaced by another repository's policy.

## Reconciliation and retention

The [policy review](POLICY-REVIEW.md) lists preserved requirements and superseded authorization
implications. It distinguishes access, authentication, resource permission, contribution credit,
organizational authority, test evidence, and release approval. Private source declarations do not
automatically adopt a new public constitution.

All 13 original Markdown files receive individual treatment. Additional guides and review records
are included in the same inventory and validation. Original history and attribution remain intact.
Existing logo bytes, workflow behavior, action pins, and runner contracts are preserved. No legal
agreement, source notice, branch protection, permission, or production setting is changed by prose.

## Validation and open decisions

Use [VERIFY.md](../VERIFY.md) for commands and [the reconstruction review](RECONSTRUCTION-REVIEW.md)
for actual results. Scope and byte fingerprints are in [change-manifest.json](change-manifest.json).
Founder/Manager policy review, identity selection, private security follow-up, and unavailable
visual or provider evidence remain explicit holds.

Organization-wide Git reconciliation is a separate private ledger, not public repository content. A
repository being inventoried does not make a branch, worktree, or cache eligible for deletion. Merge
and cleanup remain subject to their own verified conditions.
